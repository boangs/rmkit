# 首页插画素材

放这里的图会按「季节 + 天气」自动选用, 文件名必须完全一致。缺图时自动回落: 夜间图 → 同款白天图 → 自带的矢量插画。

- 尺寸: **1600 × 1200 像素 (4:3)**, PNG, 不要透明通道。
- 会按屏幕比例居中裁切: Paper Pro 上接近 4:3, Paper Pro Move 上接近 1:1, **主体放中间, 四周留出余量**。
- 墨水屏注意: 水墨 / 淡彩风格, 大面积留白; 避免整片深色 (刷新慢、易残影); 避免细密纹理与噪点 (抖动后发脏); 不要文字和边框。
